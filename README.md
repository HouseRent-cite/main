# Тихий берег — сайт аренды домов и бани

Статический сайт для GitHub Pages + база Supabase (данные, вход в админку, фото).

- Сайт: `index.html`, страница объекта: `object.html?id=…`
- Админка: `/admin/` (вход по email и паролю)
- Настройка подключения: `assets/js/config.js`
- SQL для Supabase: `supabase/01_setup.sql`, `supabase/02_add_admin.sql`

Полная пошаговая инструкция — в файле **ИНСТРУКЦИЯ.md**.
